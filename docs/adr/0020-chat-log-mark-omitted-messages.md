# ADR 0020: chat-log show で省いたメッセージに印を出す

ステータス: 採択（未実装）

## 文脈

`chat-log show`（[ADR 0011](0011-cli-for-ai-agents.md)）のテキストの出力は、表示するものが無いメッセージを、見出しも出さずに省く（[ADR 0013](0013-chat-log-output-corrections.md)）。
番号は詰めないので、番号の飛びが省いたことを示す。
[ADR 0019](0019-chat-log-thinking-around-hits.md) で、本文が空の思考は、`--thinking` や `--around` があっても出さないことにした。
思考のブロックの 87.5% は本文が空なので、思考だけのメッセージの多くが省かれる。

[ADR 0019](0019-chat-log-thinking-around-hits.md) の実装の後、文脈を持たないエージェントに、ヘルプだけを頼りに `chat-log` で過去の決定を探させた。
次のように報告された。

- 番号が飛んでいた（#415、#419、#423、#431、#435、#439 など）。
- ヘルプの「表示するものが無いメッセージは出さない」に当たると思われるが、出力の中に省いたことを示す印が無いので、最初は欠けたように見える。

[ADR 0013](0013-chat-log-output-corrections.md) は、出力を短くするために見出しも出さないことにした。
いまは、省いたものが「中身の無いもの」か「`--thinking` で読めるもの」かも、出力からは分からない。

## 実装すること

- `show` のテキストの出力で、省いたメッセージが続くところに、1行の印を出す。
  - 省いたメッセージが1件：`（#<番号> は省いた：<理由>）`
  - 続けて複数件：`（#<最初>〜#<最後> は省いた：<理由>）`
- 理由は次の2つ。
  - 省いたメッセージのどれかに、本文のある思考がある（`--thinking` が無く、`--around` でもないために出さなかった）：`思考だけ。--thinking で出す`
  - それ以外（本文が空の思考だけ、内容が無いなど）：`表示する本文が無い`
- 印は、出したメッセージと同じく空行で区切る。
- ページ（`--limit` の範囲）の先頭と末尾で省いたメッセージにも印を出す。
- `--json` は変えない（もともと省かない）。
- `context` は変えない（テキストを持つメッセージだけを選んで出す）。
- ヘルプの `show` の説明の「番号の飛びは省いたメッセージ」を、印の説明に改める。

## 実装しないこと

- 省いたメッセージの見出しを出すこと（印の1行にまとめる）。
- 理由を細かく分けること（本文が空の思考、内容の無いメッセージなどの区別）。

## テスト設計

### 関数（`bun test`）

1. ページのメッセージの並びから、出すメッセージと印の並びを作る関数：1件の省略、続けて複数件の省略、先頭と末尾の省略、省略の無いページ。
2. 理由：本文のある思考を含む省略は `思考だけ。--thinking で出す`、含まない省略は `表示する本文が無い`。

### `chat-log`（`bun test`、コマンド）

3. 本文が空の思考だけのメッセージと、本文のある思考だけのメッセージを含むセッションで、`show` に印が出て、番号と理由が正しい。
4. `show --thinking` と `show --around` では、本文のある思考だけのメッセージは出て、印は本文が空のものだけに出る。
5. `--json` の出力は変わらない。
6. ヘルプに印の説明が出る。

## トレードオフ

- 省いたところごとに1行増える。続けて省いたものは1行にまとめるので、増え方は省いたところの数に比例し、件数には比例しない。
- 理由を2つに丸めるため、`表示する本文が無い` の中身（空の思考か、内容の無いメッセージか）は分からない。どちらも読むものが無い点は同じである。
